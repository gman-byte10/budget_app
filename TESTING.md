# Try this first 🌅

A 5-minute path to exercise everything. Start the app:

```powershell
npm run dev:ai      # app + AI proxy together
```

Open the **Local** URL on your computer, or the **Network** URL on your phone (same Wi-Fi → Add to Home Screen).

## 1. Fastest way to see it all working
**Settings (⚙️) → Try it out → 🎲 Load demo data.** Instantly fills 3 months of data so every screen + chart is populated. (Use **Reset everything** later to clear it and start real.)

## 2. The daily loop (the thing you'll actually do)
- Tap **+** → type an amount on the keypad → pick a category → **Save** (aim for <5s).
- Try natural language: type `12 lunch yesterday` in the "Type it" box → tap **✨**.
- Watch the 🔥 streak and the 7-day dots on Home update.

## 3. Budgets + safe-to-spend
- **Budget** tab → tap a category → set a monthly amount.
- Home shows **Safe to spend** = all your budgets minus what you've spent.
- Tap a category → **Log expense** right from the Budget screen.

## 4. Credit card payment (your use case)
- **Budget → the "💳 Plan a payment for …" card** (or **+ Category → Credit-card payment fund**).
- Enter **how much you plan to pay this month** → Save. It's now counted in your budget.
- Tap that row → **💳 Make a payment** (amount pre-filled) → choose the account → Pay.
- The row shows **"$X to pay · $Y paid of $Z planned"** and the card's real **"owe"** balance.

## 5. Rollover (envelopes)
- Give a flexible category (e.g. Dining) **Roll over** = on.
- Under-spend one month → next month's effective budget grows; overspend → it starts in the hole.
- Past months freeze when you **Close month** (Budget screen). You can **Reopen** if needed.

## 6. Goals, recurring, insights
- **Goals** tab → create one → Add money → watch the bar.
- **Settings → Automate → Recurring** → add rent/salary.
- Home → **📈 Insights** → category donut, daily heatmap, trends.

## 7. AI (optional)
- **Settings → AI assist → toggle on → paste a key** (Gemini is cheapest: aistudio.google.com/apikey).
- Try **🤖 Ask the Coach** on Home, and **✨** category suggestions on the + screen.
- Watch cost in **Settings → AI assist → This month** (capped, so it can't run away).

## 8. Appearance & safety
- **Settings → Appearance → Dark** (or System).
- **Settings → Backup → Export** to save a JSON copy. Import restores it.

---

**If anything looks off**, jot down what screen + what you did, and we'll fix it. Everything stays on your device; nothing is sent anywhere except the AI calls you explicitly trigger.
